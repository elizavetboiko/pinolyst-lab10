# Інструкція до Лаби 10 — що зробити руками

## 1. WayForPay (кабінет і магазин)
1. Зареєструйтеся на https://wayforpay.com (потрібен **український номер +380** для SMS).
2. Створіть магазин (мерчант):
   | Поле | Значення |
   |---|---|
   | Назва | Лілея |
   | Сайт | `https://ВАШ-ЛОГІН.github.io/lileia-lab11/` |
   | Опис | Інтернет-магазин косметики, засобів догляду та товарів для дому з доставкою по Україні. |
   | Категорія | Косметика та парфумерія |
   | E-mail / телефон | hello@lileia.com.ua / +380 44 765 43 21 |
3. Верифікацію не проходьте — для завдання не потрібно.
4. Створіть платіжне посилання: товар «Доступ до Лілея Club — 1 місяць», ціна **99 грн**. Скопіюйте посилання.
> **Немає номера +380?** Тоді кабінет створити не вийде. У звіті чесно напишіть про це; платіжна кнопка на сторінці залишається демонстраційною, а справжню оплату показано в Лабі 11 через тестовий мерчант WayForPay.

## 2. Закритий Telegram-канал
1. Telegram → «Новий канал» → назва **Лілея Club 💜**, опис: «Закритий клуб інтернет-магазину «Лілея»: ранні розпродажі, новинки та добірки догляду. Доступ — 99 грн/міс.».
2. Аватар — `channel_avatar.png`.
3. Тип каналу — **Приватний (Private)**.
4. Керування каналом → **Запрошувальні посилання** → створіть посилання (за бажанням — «Заявки на вступ», щоб схвалювати лише тих, хто оплатив).
5. Два перші пости:
   - Вітаємо в Лілея Club! Тут першими з'являються розпродажі, новинки й промокоди. Закріпили правила клубу 💜
   - Добірка тижня: зволоження на зиму — сироватка з гіалуроновою кислотою, денний крем SPF 30 і крем для рук «Півонія». Промокод CLUB10 дає −10 % до неділі.

## 3. Кнопка й сторінка
1. У `content/site.json` замініть `links.channel_join` на ваш join-лінк, а `links.channel_payment` — на платіжне посилання (якщо є).
2. Запустіть `python tools/build.py lab10` або замініть адреси прямо в `index.html` і `subscribe_button.html`.
3. Опублікуйте репозиторій на GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
